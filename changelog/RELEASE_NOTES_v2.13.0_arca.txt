■ 한 줄 요약

세션 보고서를 보기 편하게 바꾸고, 판마다 메모리가 쌓이는 원인을 찾는 '누수 추적' 모드를 추가했습니다. 듀얼 GPU(Lossless Scaling)에서 VRAM이 부풀어 보이던 문제도 고쳤습니다.


■ 바뀐 점

1. 보고서 자동 새로고침
 - 웹 페이지(http://127.0.0.1:6977/)의 세션 보고서가 레이드 중 10초마다 저절로 바뀝니다. 이제 F5를 안 눌러도 됩니다.
 - 스크롤 위치와 펼쳐 둔 항목은 그대로 유지됩니다.

2. '지난 기록' 탭
 - 게임을 다시 켜도 이전 세션(최근 15개)의 레이드 기록을 웹 페이지에서 볼 수 있습니다.

3. Alt+F4·튕김으로 나간 판도 기록
 - 전에는 레이드를 끝까지 마쳐야만 보고서에 남았습니다.
 - 이제 1분마다 저장하고, 레이드 중 게임을 닫으면 닫는 순간 한 번 더 저장합니다.

4. 새 모드 '누수 추적'
 - 판을 거듭할수록 메모리가 쌓이는 원인(어떤 모드가, 무엇을 늘리는지)을 찾는 설정을 F12 '모드'에서 한 번에 켭니다.
 - 5분마다 약 1초 멈춤이 있습니다. 원인을 찾을 때만 켜고, 평소에는 '자동 정리'를 권장합니다.

5. Ctrl+F9로 모드 바꾸기 + '꺼짐' 모드
 - 게임 중 Ctrl+F9를 누를 때마다 자동 정리 → 간단 확인 → 집중 분석 → 누수 추적 → 꺼짐 순서로 바뀝니다.
 - '꺼짐'은 이 모드가 아무것도 하지 않는 상태(원래 게임과 같음)입니다. Ctrl+F9로 다시 켤 수 있습니다.

6. F12 글자 잘림 수정
 - '현재 상태'와 버튼이 창 전체 너비를 쓰고, 긴 줄은 줄바꿈됩니다.

7. VRAM을 그래픽카드별로 측정 (듀얼 GPU · Lossless Scaling)
 - 전에는 모든 그래픽카드의 VRAM을 더해서, 듀얼 GPU에서는 숫자가 부풀었습니다.
 - 이제 게임이 쓰는 카드만 'VRAM'으로 세고, 다른 카드(Lossless Scaling 쪽)는 이름·용량과 함께 따로 보여 줍니다.
 - VRAM 경고는 카드가 95% 이상 차고 실제로 시스템 메모리로 1GB 이상 넘쳤을 때만 뜹니다. (게임은 VRAM을 일부러 꽉 채워 쓰기도 해서 %만으로는 판단할 수 없습니다)

8. 기타 수정
 - 2판째부터 '레이드 후 남은 메모리'가 마이너스로 나오던 계산 오류를 고쳤습니다.
 - 누수 추적 중 1초 멈춤이 '게임 자체' 탓으로 잘못 찍히던 문제를 고쳤습니다.


■ 설치

 - zip을 SPT 폴더(예: E:\SPT 4.1)에 그대로 풀어서 덮어쓰면 됩니다.
 - v2.12.0에서 쓰던 설정은 그대로 유지됩니다. (이름이 길던 설정 몇 개는 이름만 짧아졌습니다)
 - Ctrl+F9의 역할이 '원인 추적 켜고 끄기'에서 '모드 바꾸기'로 바뀌었습니다.


■ 확인 범위

 - RTX 4080 + RTX 4060 듀얼 GPU(Lossless Scaling) PC에서 실제 레이드로 확인했습니다.
 - 그래픽카드가 한 장이거나 AMD·내장 그래픽인 환경은 아직 확인하지 못했습니다. 이상하면 알려 주세요.
