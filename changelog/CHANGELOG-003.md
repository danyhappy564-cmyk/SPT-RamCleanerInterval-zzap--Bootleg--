- 2026-10-10 12:23 (KST) — **v2.13.0: VRAM을 그래픽카드별로 따로 재기 (듀얼 GPU·Lossless Scaling 대응) + VRAM 경고는 '실제로 넘쳤을 때'만**
  - 전에는 이 게임이 쓰는 VRAM을 **모든 그래픽카드에서 합산**했음. 듀얼 GPU(게임은 1번 카드, Lossless Scaling 프레임 생성은 2번 카드)에서는 게임이 2번 카드에 둔 화면 복사용 메모리까지 더해져 부풀 수 있었음(코드상 그래야 함, 미검증).
  - 이제 **게임이 주로 쓰는 카드만** 'VRAM'으로 셉니다. F12 '현재 상태'·웹 페이지·로그에 따로 나오는 것:
    - 게임 그래픽카드 전체 사용량(모든 프로그램 합계 — 한 카드로 Lossless Scaling을 돌리면 그 몫도 여기 들어감) + 다른 프로그램 몫
    - 다른 그래픽카드 사용량(Lossless Scaling 쪽 카드). 그래픽카드가 둘뿐이면 이름·용량도 표시
    - 게임이 다른 카드에 둔 양(화면 복사용, VRAM에선 뺌)
  - **VRAM 경고 기준 변경:** 게임은 VRAM을 일부러 꽉 채워 쓰기도 해서 %만으로는 넘쳤는지 알 수 없음. 2026-10-10 로그에서 97~99%가 계속 찍혔지만, 시스템 메모리로 넘친 양('공유')은 최대 0.38GB였음. 이제 **카드 전체 사용량이 기준(95%) 이상이고, 넘친 양이 1GB 이상**일 때만 경고합니다. 기준은 새 설정 '09 · VRAM 넘침 기준 (GB)'에서 바꿀 수 있고, 0이면 옛날처럼 %만 봅니다.
- 2026-10-10 12:17 (KST) — **v2.13.0: Ctrl+F9로 모드 바꾸기 + '꺼짐' 모드 + F12 글자 잘림 수정**
  - 전에는 Ctrl+F9가 '원인 추적 모드'만 켜고 껐음. 모드를 바꾸려면 F12나 웹 페이지에 들어가야 했음.
  - 이제 Ctrl+F9를 누를 때마다 **자동 정리 → 간단 확인 → 집중 분석 → 누수 추적 → 꺼짐 → 자동 정리 …** 순서로 바뀌고, 게임 알림으로 지금 모드와 다음 모드를 알려 줍니다. '직접 설정' 상태에서 누르면 자동 정리부터.
  - 새 모드 **꺼짐**: 이 모드가 아무것도 안 함(자동 정리·경고·화면 표시·측정 전부 멈춤 = 원래 게임). 웹 페이지와 단축키만 남아서 다시 켤 수 있습니다. 꺼짐에서 나오면 워킹셋 정리 설정은 꺼지기 전 값으로 돌아갑니다.
  - F12 '현재 상태'·'수동 실행'이 오른쪽 좁은 칸(약 270px)에 그려졌고, 특히 수동 실행 버튼 8개가 그 칸에 **옆으로 나란히** 끼어서 글자가 잘렸음 → 이름 칸을 없애고 창 전체 너비로, 버튼은 세로로 한 줄씩, 긴 줄은 줄바꿈. 맨 위에 지금 모드 줄 추가, 수동 실행에 [모드 바꾸기] 버튼 추가.
  - 이름 칸(약 260px)을 넘던 긴 설정 이름도 줄임(예: '의심 기준: 레이드 후에도 남는 관리 메모리 (MB)' → '의심 기준: 레이드 후 남는 메모리 (MB)'). 설정 값은 그대로라 다시 설정할 필요 없음.
- 2026-10-10 12:04 (KST) — **v2.13.0: 모드에 '누수 추적' 추가**
  - 전에는 집중 분석을 골라도 누수 추적(06)·모드별 오브젝트(11)가 꺼져 있어서, 판마다 메모리가 쌓이는 원인을 찾으려면 F12에서 따로 켜야 했음.
  - 이제 F12 '모드'에서 **누수 추적**을 고르면 메모리 원인 찾기에 필요한 것만 한 번에 켭니다: 간단 확인 + 모드별 메모리 생성량 + 누수 추적 + 모드별 오브젝트 증가 + [실험] 무거운 아이템. 끊김 원인 추적과 끊김 알림은 끕니다(누수 추적 자체가 몇 분마다 짧게 끊기므로).
- 2026-10-10 02:01 (KST) — **v2.13.0: '레이드 후 남은 메모리'가 2판째부터 마이너스로 나오던 문제 수정**
  - 사용자 로그(2026-10-10, 3판)에서 2·3판이 "-1.77GB", "-1.24GB"로 나옴. 비교 기준을 '레이드 로딩 시작 때' 메모리로 잡았는데, 2판째부터는 그 시점에 이미 로딩 쓰레기가 2GB 넘게 쌓여 있어서 기준이 부풀었음.
  - 이제 2판째부터는 **지난 판 정리(GC) 뒤 값**과 비교합니다(정리 뒤 ↔ 정리 뒤). 같은 로그로 다시 계산하면 2판 +0.99GB, 3판 +0.48GB가 맞는 값입니다. 첫 판은 전처럼 '레이드 전'과 비교.
- 2026-10-09 11:21 (KST) — **v2.13.0: 레이드 도중 Alt+F4·튕김으로 나가도 그 판 기록이 남음**
  - 전에는 보고서 파일이 판이 **끝날 때만** 저장돼서, 레이드 중 게임을 끄면 그 판이 통째로 사라졌습니다.
  - 이제 레이드 시작 1분 뒤부터 **1분마다** 진행 중인 판을 파일에 저장하고, 레이드 중 게임을 닫으면(Alt+F4) **닫는 순간 한 번 더** 저장합니다.
  - 보고서·'지난 기록'에서 그런 판은 **'게임 종료로 중단 · 시각'**(정상 종료 처리됨) 또는 **'끝나지 않음 · 시각까지 기록'**(튕김 등으로 마지막 1분 저장분)으로 표시됩니다.
  - 1분 안 된 판은 지금처럼 저장하지 않습니다. 저장은 1분에 한 번이라 레이드 중 부담은 거의 없습니다(코드상, 인게임 미검증).
